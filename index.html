Trabajo de Fin de Grado

Descripción

Aplicación web que analiza automáticamente vídeos de partidos del Real Jaén CF. A partir de un clip, un pipeline de inteligencia artificial detecta y sigue a jugadores, porteros, árbitros y balón, asigna equipos y roles, proyecta a los jugadores sobre un minimapa del campo y calcula métricas.

Los resultados (vídeos anotados, mapas de calor, grafos, informes de jugador y estudio táctico) se consultan desde un panel web que además incluye el calendario de la temporada con sus estadísticas.

La aplicación se divide en tres piezas:

  • Frontend: HTML y JavaScript. Es lo que ve el usuario.
  • Backend: Python (FastAPI). Expone una API REST y lanza los análisis.
  • Pipeline de IA: main.py. Hace el trabajo pesado sobre el vídeo.

Los datos de temporada se guardan en una base de datos SQLite.
